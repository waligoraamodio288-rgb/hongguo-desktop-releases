# 当前集及后3集自动预缓存（集成材料）

当前源可打开后，顺序预下载后3集。HEVC 原生模式只下载原片，不进行 HLS/H.264 编码；转码模式先完成当前整集，再串行准备后续。暂停仍继续。再次播放完整缓存集直接复用对应模式的产物。

本仓库没有应用源码，本 PR 提供新写模块和接入契约，**合并本材料不会修改已发布播放器**。不包含私有完整源码、原始 bundle、EXE、原片或用户数据。代码基于本机1.0.12环境验收，作者须适配真实私有源码。

- `src/desktop_prefetch.py`：调度 owner，当前优先、代际取消、有序下载/转换。
- `src/desktop_playable_cache.py`：完整可播缓存 owner，内容校验、原子提交、策略指纹及配额。
- [INTEGRATION.md](INTEGRATION.md)：宿主接口、接线、失败路径与回滚。

## 公开可复现验证

Python 3.10+，仓库根目录：

```powershell
pwsh -NoProfile -Command "python -I contributions/desktop-prefetch-cache/tests/run.py"
```

47项 unittest 使用自造原片、假 HLS 片段和 Event 验证并发/顺序，不访问网络、不依赖私有应用或 PyAV。覆盖缓存命中不转码、完整性损坏、取消、前台抢占、队列失败隔离、源/策略变化、配额与未知文件保护。新增回归检查同名同元数据片源不会串集、恢复时完成标记最后出现，以及取消/复制中断后的清理。播放列表必须以 #EXTM3U 开始。宿主线程启动失败接线另列为集成门禁。

## 本机真实验证摘要（与上述 fixture 分开）

同一实际安装环境中，当前及后3集共231.596秒媒体完成可播预缓存约88.844秒，四集均完成音视频解码。缓存回放0.609–0.921秒；禁止原片网络与 encoder 调用后仍成功。上述为单机单轮观测，不承诺其它硬件/网络耗时。公开目录不附观看标识、原片或完整日志。

Related to #23、#181。建议作者接入、发布，并回归“当前及后3集、暂停继续、缓存复用”后关闭；此材料合并时不要自动关闭。#104/#169 未复现原报告，#17/#161 缓存目录设置与管理界面不在范围内。

复审补充：过期的排队前台任务不再抢编码槽；按HLS完整标签和必需字段检查产物；损坏JSON清单按未命中回退；缺少清单的自有缓存可安全回收。

HLS校验按[RFC 8216](https://www.rfc-editor.org/rfc/rfc8216.html#section-4.3.3.1)检查必需的 TARGETDURATION、fMP4 MAP所需的VERSION>=6，以及片段时长和标签顺序。测试片段仍为fake字节，不能代替真实媒体解码。

本轮回执修复：源加载与编码槽分开；完整文件校验不持调度锁；损坏 owner 标记作为未知缓存保留；取消先于配额回收；不可访问的可选缓存不阻止服务启动；LRU 时间戳不可写仍可命中。新增原生模式后三集零编码、渐进当前源尚未完整与阻塞旧下载切集回归。保留此前内容 SHA256 防串集与严格 HLS 校验。

Related to #202、#199、#173，仅覆盖预取/切集等待的路径；未复现这些报告全部中断原因，不能直接关闭。#151/#69 的跨设备 CPU、温度和功耗仍需维护者实测，不能用取消转码或材料合并代替验收。

复核审查回执后按[RFC8216 §4.3.3.4](https://www.rfc-editor.org/rfc/rfc8216.html#section-4.3.3.4)允许单个ENDLIST出现在列表任意位置；它只表示不再追加，不是解析终止符。新增前置/媒体标签间位置与尾部不完整EXTINF回归，重复ENDLIST仍拒绝。

本轮复审补充：切集取消可中断原片和产物SHA256校验，后台验证会及时释放调度槽；不可实现的配额预先拒绝并保留已有缓存；可选缓存不可用时store不再读取原片。seek窗口保留显式copy参数，由底层编码器拒绝不支持的组合，不静默改为H.264。

第二轮复审：可选缓存身份不能序列化时保留编码成功结果；先核验替换目标再驱逐其他缓存；诊断回调异常不影响播放；完整缓存拒绝加密或GAP清单。当前 Python 55 项通过。
